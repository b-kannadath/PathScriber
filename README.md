## Install

PathScriber has not been released yet. Once it is published on PyPI:

```bash
pip install pathscriber
```

To install from source:

```bash
git clone https://github.com/b-kannadath/pathscriber.git
cd pathscriber
pip install .
```

Requires Python 3.10 or later.
